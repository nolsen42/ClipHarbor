What it does

ClipHarbor is a friendly window around yt-dlp and FFmpeg, the open-source tools most downloaders use behind the scenes.

Any quality, video or audio

MP4, MKV or WEBM up to the best the site offers, 4K and 8K included. Or just the sound as MP3, M4A, OPUS, FLAC or WAV.

Only the part you want

Type a start and end time and only that stretch is downloaded. Much quicker for one moment from a long video or stream.

GIFs from any clip

Turn a short video into a looping GIF or animated WebP, in the size you choose.

Small enough for Discord

Pick a size limit (20, 50, 100 or 500 MB) and the video is re-encoded to fit, as sharp as the size allows.

Playlists and channels

Pick which videos you want from a playlist, or follow a channel and new videos download by themselves.

Skip the sponsor reads

Optionally cut out or mark sponsor segments in YouTube videos, using the community-made SponsorBlock list.

Subtitles

Choose languages and have them built into the video, or saved next to it.

Send from your browser

Right-click a video and choose Download with ClipHarbor, with the extension for Chrome, Edge, Brave and Firefox.

Keeps itself working

Sites change often. ClipHarbor updates its download engine by itself, so links keep working.

Questions

The honest answers, including the slightly awkward ones.

Is it really free? What's the catch?

There isn't one. ClipHarbor is a hobby project with no ads, no tracking, no paid tier and no account. All the code is public on GitHub, so anyone can check what it does.

Windows says "Windows protected your PC", or my antivirus warns about it

Signing a program with a certificate Windows trusts costs money every year, and ClipHarbor isn't signed yet. New unsigned programs that download things sometimes get flagged by antivirus software by mistake. On the blue Windows screen, press More info → Run anyway. If you'd rather check first, the source code and the build steps are all public, and every file is built by GitHub, not on someone's computer.

Why isn't it in the Google Play Store?

Google Play doesn't allow apps that download from YouTube, so ClipHarbor is installed from its own file. It updates itself from GitHub, and Android asks you before installing each update.

Why does reading a link take a few seconds on my phone?

yt-dlp starts up and works through YouTube's checks each time you paste a link. It's quicker on a computer, and on newer phones.

Is downloading videos legal?

It depends on where you live and what you download. Saving your own videos, Creative Commons videos, or something for personal offline viewing is usually fine; sharing other people's work usually isn't. Please respect the creators and the sites' rules.

Something doesn't work

Sites change often, and ClipHarbor updates its engine every day to keep up. If a link still fails, open an issue on GitHub with the link and the message you saw.
